# Visión de Águila | Introducción al piano · Musicala

Aplicativo web **estático** en español para principiantes absolutos. Trabaja con la secuencia de notas indicada por el usuario para la introducción de **Visión de Águila**, de **Nancy Ramírez**.

## Abrirlo

1. Descomprime el ZIP.
2. Abre `index.html` en Chrome, Edge, Firefox o Safari.
3. Para compartirlo mediante una URL, publica el contenido de esta carpeta en un hosting estático (GitHub Pages, Netlify, Firebase Hosting, etc.). No requiere dependencias, servidor, instalación ni compilación.

## Incluye

- Secuencia completa: **Re♯ Mi Fa♯ Sol♯ / Si La Sol♯ Mi Fa♯ / Re♯ Mi**.
- Piano visual e interactivo que permanece visible en la zona inferior.
- Explicación de sostenidos y ubicación de Re♯, Fa♯ y Sol♯.
- Navegación por tres frases, notas resaltadas y progreso de práctica.
- Modo con pistas y modo sin pistas.
- Escucha de nota individual, frase o introducción completa a diferentes velocidades.
- Audio generado en el navegador con Web Audio API; no requiere archivos de audio externos.
- Diseño adaptable a computador y celular.

## Nota pedagógica

La reproducción **no busca imitar la interpretación original** ni su ritmo: toca las notas proporcionadas con tiempos iguales para facilitar que la persona las identifique. No se incluyen partituras, acordes, letra ni pistas grabadas. Las notas se presentan todas en la misma zona central del piano para simplificar la primera exploración.

## Archivos

- `index.html`: interfaz y contenido.
- `styles.css`: estilos.
- `app.js`: interacción, piano y audio.
- `assets/icon.svg`: favicon.
